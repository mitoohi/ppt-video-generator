# 递进式提问流程

## 设计原则

- **混合交互**：关键决策用 AskUserQuestion（选项式），开放补充用纯文本追问
- **4 轮提问**，每轮 2-4 题，总计 ≥10 题
- **渐进深入**：主题方向 → 受众定位 → 内容结构 → 风格细节
- **提前终止**：如果用户在某轮给出了足够详细的信息，可跳过后续同类问题

## 4 轮结构

```
第 1 轮：主题与目标（必选项 + 文本）
    ↓ 分析用户意图
第 2 轮：受众与调性（必选项 + 文本）
    ↓ 确定内容深度
第 3 轮：内容结构（必选项 + 文本）
    ↓ 确定大纲骨架
第 4 轮：风格与偏好（必选项）
    ↓ 确定模板/音色/节奏
→ 输出 brief.md
```

## 每轮执行规则

### 第 1 轮：主题与目标

**目的**：明确"讲什么"和"为什么讲"

使用 AskUserQuestion 提问：
1. 内容领域（技术/商业/生活/教育/其他）
2. 视频目的（科普/教程/观点输出/产品介绍/其他）

紧接纯文本追问：
3. "请用 1-3 句话描述你想讲的核心内容是什么？"
4. "这个视频最想让观众记住的一个关键信息是什么？"

### 第 2 轮：受众与调性

**目的**：明确"讲给谁"和"用什么语气"

使用 AskUserQuestion 提问：
1. 目标受众（小白/有基础/专业人士/通用）
2. 表达风格（严谨专业/轻松幽默/故事叙事/干货密集）

纯文本追问：
3. "观众看完后，你希望他们能做到什么？（行动号召）"

### 第 3 轮：内容结构

**目的**：确定大纲骨架和信息密度

使用 AskUserQuestion 提问：
1. 内容组织方式（总分总/递进式/问题-方案/对比分析/时间线）
2. 是否有必须包含的要点（是/否）

纯文本追问（如果上题选"是"）：
3. "请列出你认为必须覆盖的 3-5 个要点"

纯文本追问：
4. "有没有什么常见误区或反直觉的点想特别强调？"

### 第 4 轮：风格与偏好

**目的**：确定视觉和听觉呈现

使用 AskUserQuestion 提问：
1. PPT 模板风格（现代极简/温暖柔和/赛博科技）
2. 口播音色偏好（温柔女声-晓晓/活力女声-晓伊/沉稳男声-云希/年轻男声-云扬）
3. 语速偏好（正常/稍快/稍慢）

## 停止条件

满足以下全部条件时结束提问，进入脚本生成：

- [x] 核心主题明确（能用一句话概括）
- [x] 目标受众明确
- [x] 至少有 3 个内容要点
- [x] 模板和音色已选定
- [x] 总问题数 ≥ 10

## 输出格式

提问结束后，将收集到的信息整理为 `brief.md` 并保存到项目目录：

```markdown
# 创作简报

## 基本信息
- 主题：{主题}
- 领域：{领域}
- 目的：{目的}
- 目标受众：{受众}
- 核心信息：{一句话}

## 内容要求
- 组织方式：{方式}
- 必含要点：
  1. ...
  2. ...
  3. ...
- 特别强调：{误区/反直觉点}
- 行动号召：{CTA}

## 风格设定
- 表达风格：{风格}
- 模板：{模板名}
- 音色：{音色 ID}
- 语速：{语速}
- 预期时长：3-5 分钟
- 预期页数：8-12 页
```

## 异常处理

- 用户说"你来决定"→ 使用默认值（现代极简 + 晓晓 + 正常语速），但仍需确认主题和要点
- 用户给出非常详细的需求描述 → 可压缩为 2 轮提问，跳过已知信息
- 用户中途想改之前的回答 → 允许回溯，更新 brief.md 对应字段
